CARA MEMPERBARUI APK (lewat GitHub)
1. Ekstrak zip ini.
2. Di repository GitHub: Add file > Upload files.
3. Seret SEMUA isi folder hasil ekstrak (folder "app", build.gradle.kts, dll.) ke halaman upload.
   File dengan nama sama akan otomatis diganti, file baru ditambahkan.
4. Commit changes, buka tab Actions, tunggu centang hijau, unduh "MapChannelsTV-apk".

CATATAN
- File lama app/src/main/res/drawable/ic_launcher.xml dan banner.xml tidak dipakai lagi (boleh dibiarkan atau dihapus).
- Untuk mengganti alamat halaman: edit MainActivity.kt, ubah nilai URL.

KONTROL
- Mouse USB/Bluetooth: langsung bisa (klik, geser, roda mouse = zoom).
- Remote TV: tekan panah, kursor oranye muncul.
    Panah            : gerakkan kursor (tahan = makin cepat)
    OK (tekan)       : klik
    OK (tahan)+panah : geser peta
    CH+/CH-, Page Up/Down, FF/Rewind : zoom in/out
    Menu             : mode zoom (kursor biru, panah atas/bawah = zoom); tekan lagi untuk keluar
